# Evaluación 2 - Mesalab (González Tapia)

Proyecto web de evaluación que incluye páginas estáticas y un servidor Node.js simple.

## Descripción

Este repositorio contiene una pequeña aplicación web con un formulario de login y un panel. Está pensada para fines educativos y de evaluación.

## Requisitos

- Node.js (para ejecutar `server.js`).
- Navegador web moderno para abrir las páginas estáticas.

## Estructura de archivos (resumen)

- `index.html` - Página principal
- `login.html` - Formulario de acceso
- `panel.html` - Panel tras el login
- `main.js` - Lógica del cliente
- `style.css` - Estilos
- `server.js` - Servidor Node.js (opcional para servir la app)
- `evaluacion-u2-mesalab-gonzalez-tapia/` - Carpeta con recursos adicionales

## Instalación y ejecución

1. (Opcional) Instalar dependencias si existe `package.json`:

```bash
npm install
```

2. Ejecutar el servidor Node.js (si se desea servir la app):

```bash
node server.js
```

Luego abrir `http://localhost:3000` (o el puerto que el servidor indique) o abrir `index.html` directamente en el navegador.

## Notas

- Ajusta el puerto o comandos según la configuración de `server.js`.
